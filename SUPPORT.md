# Getting Help with Dayu

Dayu welcomes users and contributors from academia, industry, and the wider community. Choose the channel that
matches your question so it reaches the people responsible for that work.

| Topic | Where to go |
| --- | --- |
| Setup, usage, and tutorials | Start with the [documentation site](https://dayu-autostreamer.github.io/docs/); ask a question in [Dayu issues](https://github.com/dayu-autostreamer/dayu/issues). |
| Reproducible system bug or feature proposal | Use the appropriate [Dayu issue template](https://github.com/dayu-autostreamer/dayu/issues/new/choose). Include the version, configuration, expected/actual behavior, and a minimal reproduction where applicable. |
| Repository implementation docs or examples | Open an issue or PR in [dayu-autostreamer/dayu](https://github.com/dayu-autostreamer/dayu). |
| Website content, navigation, or translation | Open an issue or PR in the [documentation website repository](https://github.com/dayu-autostreamer/dayu-autostreamer.github.io/issues). |
| Contributing, design review, or finding a reviewer | Read [CONTRIBUTING.md](CONTRIBUTING.md), then comment on the relevant issue/PR or contact a [Maintainer](MAINTAINERS.md#maintainers). |
| Governance, responsibilities, or membership | Read [GOVERNANCE.md](GOVERNANCE.md) and [MAINTAINERS.md](MAINTAINERS.md). Discuss general proposals in an issue; send sensitive personnel matters privately to a non-conflicted Maintainer or TSC member. |
| Suspected security vulnerability | Follow the private reporting channels in [SECURITY.md](SECURITY.md). Do not post vulnerability details in public issues or PRs. |
| Harassment or other conduct concern | Use the private contacts and conflict-handling procedure in [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md#enforcement). |

For general project or research contact:

- [Wenhui Zhou (whzhou@smail.nju.edu.cn)](mailto:whzhou@smail.nju.edu.cn)

Public issues help others learn from answers. Remove credentials, access tokens, private endpoint details, and
personal data from configuration and logs before sharing them. For a private report, contact only the appropriate
non-conflicted recipients; do not copy someone involved in the complaint.
